コードを確認したところ、Meta Quest 3とPCの接続について以下の設定が必要なことがわかりました：

1. 開発者モードの設定：

- Meta Quest 3で開発者モードを有効にする必要があります

- 設定方法：

1. Meta Quest 3の設定アプリを開く

2. 「システム」→「開発者」を選択

3. 「開発者モード」をオンにする

4. USBデバッグの設定：

- Meta Quest 3でUSBデバッグを有効にする必要があります

- 設定方法：

1. 開発者モードを有効にした後

2. 「USBデバッグ」をオンにする

3. PC側の設定：

- Oculus Developer Hub（ODH）をインストールする必要があります

- 設定方法：

1. Oculus Developer Hubをダウンロードしてインストール

2. PCとMeta Quest 3をUSBケーブルで接続

3. ODHでデバイスが認識されていることを確認

4. アプリの設定：

- アプリの設定で以下の項目を確認：

1. OpenXRPackageSettings.assetでMeta Quest 3がサポートデバイスとして有効になっているか

2. forceRemoveInternetPermissionが適切に設定されているか

3. 必要なインタラクションプロファイルが有効になっているか

4. 接続の確認方法：

5. Meta Quest 3をPCに接続

6. ODHでデバイスが認識されていることを確認

7. アプリを起動して、PCのキーボード入力が反映されるか確認

これらの設定が正しく行われていないと、PCのキーボード入力がMeta Quest 3のアプリに反映されない可能性があります。特に開発者モードとUSBデバッグの設定は重要です。
